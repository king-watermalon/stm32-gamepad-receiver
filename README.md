# STM32 无线手柄与接收器

一套基于 STM32F103C8T6 + SI24R1 的 2.4G 无线输入设备

## 项目组成

| 目录 | 内容 |
|---|---|
| `controller/` | 手柄固件
| `receiver/` | 接收器固件
| `hardware/` | 两块板的嘉立创 EDA 工程（`.epro2`） 

## 功能介绍

**手柄**

- 双摇杆上电自动校中点
- OLED 首页显示宠物动画，连接状态和电量
- 按住 **SW + A** 约 600 ms 进菜单；首页单击 SW 对应手柄 Start 键

**接收器**

- RGB状态灯：红 = 未连接，绿 = 手柄在线
